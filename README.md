# Конструктор учебных сценариев

Тестовое задание на Unity/C#: переиспользуемые шаги, тренировка и экзамен, настраиваемая активация, журнал событий и независимое оценивание.

Unity-проект находится в `ScenarioBuilder/`. Используется Unity 6000.4.11f1, стандартные компоненты Unity и собственный C#.

Разработка ведётся по этапам. Инструкция по настройке, контрольные примеры и техническое описание будут добавлены вместе с работающей демонстрацией.
