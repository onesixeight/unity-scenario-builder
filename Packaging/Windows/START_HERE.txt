КОНСТРУКТОР УЧЕБНЫХ СЦЕНАРИЕВ

Windows 10 версии 21H1 или новее / Windows 11, 64-разрядная система x64.
Unity Editor и Unity Hub для запуска готовой программы не нужны.

УСТАНОВКА
Скачайте ScenarioBuilder-Setup.exe со страницы релиза и запустите его.
Мастер установит программу для текущего пользователя без прав администратора.
После установки запускайте «Конструктор учебных сценариев» из меню «Пуск»
или с рабочего стола, если выбрали создание ярлыка.

ЗАПУСК БЕЗ УСТАНОВКИ
Распакуйте весь архив ScenarioBuilder-Windows.zip в отдельную папку.
Откройте ScenarioBuilder.exe. Все соседние папки и DLL должны остаться рядом.
Не запускайте программу непосредственно внутри ZIP и не переносите один EXE.

КАК ПОПРОБОВАТЬ
1. Прочитайте окно «Как пройти», затем выберите «Тренировка» и нажмите «Начать».
2. Выполняйте зелёные активные задания. Одновременно активные шаги можно
   выполнять в любом порядке. Серые ждут очереди: раннее действие — нарушение.
3. У физических станций дождитесь движения шара и реального входа/контакта.
   На S06 войдите в A, дождитесь подтверждения, затем двигайтесь в B.
4. Перед S07 включите «Питание», перед S10 — «Защита» над стендом.
5. Красная «Ошибка» намеренно имитирует нарушение для проверки правил.
6. Журнал справа прокручивается колёсиком и ползунком. После завершения
   можно выбрать другой анализатор и пересчитать тот же журнал.
7. «Повторить» начинает новое прохождение. Окно можно развернуть.

В режиме «Экзамен · перекрытие» S02 открывает группу 2, а S06 — группу 3.
Несколько групп могут оставаться активными одновременно.

УДАЛЕНИЕ
Установленную версию можно удалить через список установленных приложений
Windows. Для версии без установки достаточно удалить распакованную папку.
Сохранённые журналы остаются в папке пользователя:
%USERPROFILE%\AppData\LocalLow\ScenarioBuilder\Scenario Builder
